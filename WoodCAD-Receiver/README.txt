木工CAD 受信（風呂敷版）
=========================================================

これは何？
---------------------------------------------------------
生徒のiPadの木工CADで「先生に送る」を押した設計を、このPCで受け取るための一式です。
届いた設計は、ブラウザの「提出一覧」でサムネイル付きで見られます。

Windowsにインストールするものは何もありません。
このフォルダの外には何も書きません（レジストリにも触りません）。
だから、使い終わったら「フォルダごと消す」だけで跡が残りません。


はじめて使うとき（1回だけ）
---------------------------------------------------------
 1. このフォルダ（WoodCAD-Receiver）を丸ごと、使うPCにコピーする
      おすすめは C:\WoodCAD-Receiver のような、ふつうの場所
      ★OneDrive の中（デスクトップがOneDriveになっていることがあります）や
        ネットワークの場所は避けてください★
 2. WoodCAD.cmd をダブルクリック
      「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
      黒い窓と、ブラウザの設定画面が開きます
 3. 設定画面の「はじめての設定」で、提出一覧のパスワード（8文字以上）を決めて「保存する」
 4. 「受付を始める」
 5. 「外から受け取れるようにする」の①②③
      ① Cloudflare にログイン … ブラウザが開くので hakuryu.f5.si を選んで「Authorize」
      ② トンネルを用意する   … アドレスは woodcad-submit.hakuryu.f5.si のまま「用意する」
      ③ 外からの受付を始める … 数秒で「届きます」になります

 これで生徒のiPadから「先生に送る」が届くようになります。
 （試すときは、iPadの木工CADで何か1枚板を置いて「先生に送る」→「送る」）


ふだんの使い方
---------------------------------------------------------
 ・WoodCAD.cmd をダブルクリックするだけ
     受付もトンネルも自動で始まります（「開いたら自動で受付を始める」がオンのとき）
 ・★黒い窓は閉じないでください★
     閉じると受付が止まります。最小化しておけば邪魔になりません
 ・ブラウザの設定画面は閉じてもかまいません

 提出一覧を見る
  ・このPCで：設定画面の「提出一覧を開く」
  ・ほかのPC・電子黒板・iPadで：https://woodcad-submit.hakuryu.f5.si
      パスワードを聞かれます（ユーザー名は何でもかまいません）
  ・ふだんは同じ人・同じデータの最新だけ。「すべての送信を表示」で全部
  ・「ダウンロード」したファイルは、木工CADの「セーブデータ」→「ファイルから読み込む」で開けます
  ・「まとめてダウンロード」で、その日の分をzipでまとめて保存できます


届いた設計を持ち出す
---------------------------------------------------------
設定画面の「提出を持ち出す」に、書き出す場所（例: D:\ ）を入れて「書き出す」。

    D:\woodcad-submissions-20261023-153000\
        2026-10-23\153012_1205_山田太郎_設計1.json  … 設計
        2026-10-23\153012_1205_山田太郎_設計1.jpg   … サムネイル
        manifest.json                              … ファイルの一覧とハッシュ

1つずつ中身を照合してから「書き出しました」と出します。


このPCから消す
---------------------------------------------------------
設定画面のいちばん下「このPCから消す」から。★元に戻せません。★

 1. 「何が消えるか見る」… 消えるもの・持ち出しが済んでいるかを確かめます
      持ち出した一式をその場で開いて、中身がそろっているかも確かめます
 2. 枠に「このPCから消す」と入れて「消す」
      ランチャーが終わったあと、このフォルダが丸ごと消えて、親フォルダが開きます

手で消したいときは、「止める」を押して黒い窓を閉じてから、
エクスプローラーでこのフォルダを削除するだけでも同じです。

 ※ Cloudflare のアカウント側には、トンネル「woodcad」とアドレスが残ります。
   このPCが無ければ何も動かないので害はありません。
   別のPCで使うときは、このフォルダごと持っていけば、ログインからやり直さずにそのまま使えます。


フォルダの中身
---------------------------------------------------------
  WoodCAD.cmd        入口。これだけ押す
  runtime\node\      Node本体（同梱）
  runtime\cloudflared.exe  Cloudflare Tunnel（同梱）
  app\               受付のプログラム
  launcher\          設定画面
  data\submissions\  ★届いた設計★（日付ごと）
  config\            設定（パスワードはハッシュで保存）と Cloudflare の資格情報
  logs\              動作ログ
  tmp\               一時ファイル


このPCで WEEKY の風呂敷も動かしているとき
---------------------------------------------------------
そのままいっしょに動きます。ぶつからないようにしてあります。
  ・ポート：WEEKY は 3000、こちらは 8010（設定画面は 17445〜）
  ・トンネル：WEEKY は「weeky」、こちらは「woodcad」。別々のトンネルです
  ・Cloudflare の資格情報：こちらは自分で作ったものだけをこのフォルダに移します。
    WEEKY のものには触りません


うまくいかないとき
---------------------------------------------------------
 設定画面の右の「診断」を見てください。✕ の行が止まっているところです。
 それでも分からなければ logs\launcher.log を見てください。

  ・ポートがふさがっている → 「はじめての設定」でポートを 8011 などに変える
  ・生徒が「このページからは送信できません」 → 送信元のページが許可されていません。
      config\receiver.json の allowedOrigins に、木工CADのアドレスが入っているか確かめる
  ・生徒が「先生のパソコンにつながりませんでした」
      → このPCの受付かトンネルが止まっています。設定画面の上が「受付中（生徒のiPadから届きます）」か確かめる
